Ontology & technical reference · veh:silverado-2500hd-2003

The 2003 Silverado 2500HD, as entities, relationships, and rules.

A reasoning map for this gas LQ4 truck. When something breaks, start from the complaint, name the entity that is actually speaking, and walk the rules backward to a cause. It is not a service manual: torque specs, fluid capacities, and safety-critical procedures still belong to a factory manual.

PART 02

How to trace a cause

Four questions, asked in the same order every time. The rest of this manual is those four questions applied to this truck.

Entity

What kind of thing is speaking? A part (knock sensor), a symptom (a DTC), a condition (positive fuel trim right now), or a trend (trim rising over weeks).

Property

Which side, which cylinder, which circuit, which fluid. “Bank 1” and “front knock sensor” are different properties. Mixing them sends you to the wrong part.

Relationship

How the engine holds evidence: hasDtc (a code), hasCondition (true now), hasTrend (true across samples). A named fault class is a rule over those three.

Rule

What may follow, and in which order to check. Forward rules say “if A is confirmed, watch for B.” Backward rules say “given this complaint, rank the causes.”

Reading a fault-class rule

The project’s ontology states misfire like this:

MisfireUnderLoad ≡ Engine ⊓ (∃hasDtc.CylinderMisfire ⊔ ∃hasCondition.FailedMisfireMonitor) ⊓ (∃hasCondition.HighLoad ⊔ ∃hasTrend.RecurringHighLoad)

⊓ means and. ⊔ means or. ∃ means “has at least one.” In words: this counts as misfire under load only when there is a misfire code or a failed misfire monitor, and the engine is under high load now or has a recurring high-load trend. A lone code is not yet the class. That extra bar is the point of the ontology.

Aspect order

Air faults get the gas path measured first. Electricity faults get the circuit proven before the part is condemned. Mechanical faults get isolated (swap, compression, correlation) before a reporting sensor is replaced. Fluid faults get level, quality, and viscosity checked before an actuator is blamed for what a starved fluid can fake.

Cheap and reversible first

Impact, confidence, information gained, cost, risk, and reversibility are the six scores the software uses to rank the next action. That ranking is not the same thing as a bulletin’s own step 1. TSB 02-06-04-023A’s transcribed procedure starts by removing the intake.

Worked trace — P0332 The entity is the rear knock sensor (P0332), which is not cylinder bank 2. The corroborated bulletin’s condition is spark knock and/or an MIL with that one code, on 1999–2002 trucks. This profile is a 2003. The transcribed repair replaces the rear sensor and leaves the RTV dam open at the rear. It does not start at the connector, and it does not say the code rules detonation out.
PART 03

The two cause chains that belong to this engine

These are the GM-specific priors the Silverado cartridge actually uses. They re-rank two SAE classes that already exist. They do not add a new fault class. Both bulletins are corroborated, not read from GM’s original PDF.

Chain A — rear knock sensor, P0332, 1999–2002

corroborated TSB 02-06-04-023A. Listed trucks are 1999–2002 Silverados with 4.8 / 5.3 / 6.0 engines, including LQ4 VIN U. This profile is a 2003. The named code is P0332 only. The stated cause is corrosion of the rear knock sensor from water in the cavity, more apparent if the engine compartment is washed often. The customer comment in the bulletin is spark knock and/or an MIL. P0327 is not in that text.

Entities

  • Rear knock sensor — the bulletin’s part, P/N 10456603
  • P0332 — the only DTC the bulletin names
  • Front knock sensor — P0327 is a different circuit, not this bulletin
  • Intake that has to come off to reach the rear sensor

Properties

  • Front / rear, not left / right
  • “Rear bank” in the bulletin means the rear sensor
  • Cylinder bank 1 is still the driver’s side — a different axis

Relationship

  • Water in the rear sensor cavity → corrosion → P0332
  • The bulletin also lists audible spark knock as a customer comment
  • The RTV bead is not a closed circle; the rear stays open
First
Year and code

1999–2002 and P0332. This truck is one model year later. Do not apply the repair to a front-bank P0327.

Next
Rear sensor and open RTV dam

Remove the intake. Replace the rear sensor and tighten to 20 N·m (15 lb ft). Bead about 9 mm wide and 6 mm high. Leave the rear open. Remove the rear intake foam seal. The parts list is that one sensor, not intake gaskets.

Later
The ping the customer reported

The bulletin does not say the code means the engine is not knocking. Spark knock is the condition it opens with.

Clear the code and drive the same kind of trip that set it. A parts-kit listing that bundles intake gaskets with this bulletin number is not the transcribed procedure.

Chain B — upper intake gasket, rough idle, P0300

corroborated TSB 05-06-04-029A (June 24, 2005). The titled engines are 2002–2004 L59 flex-fuel (VIN Z). A following sentence says it may apply to regular-fuel engines including this LQ4 (VIN U). The named complaint is rough idle, misfire, and/or an MIL with P0300. The stated L59 cause is fuel pooling on the upper manifold-to-head gasket until it degrades into an unmetered air leak. The retrieved text does not name P0171, P0174, or a coolant leak.

Entities

  • Upper intake gasket
  • Teal-green P/N 89017589
  • Orange P/N 17113557 — do not install
  • Intake-to-head deck, which the bulletin says to inspect for warpage

Properties

  • Titled on L59; LQ4 is “may apply”
  • Named code is P0300, not a lean code
  • Use it only after the diagnostic check already points at a gasket air leak

Relationship

  • Degraded gasket → unmetered air → rough idle / misfire / P0300
  • An unmetered air leak can also lean the engine out; that is not a code the bulletin names
  • A one-bank lean code is not this bulletin by itself
First
The diagnostic check, not the gasket

The bulletin says to start with the Diagnostic System Check and to follow these steps only if rough idle, misfire, or P0300 already points at an intake-gasket air leak.

Next
Teal gasket, then the deck

Install teal-green P/N 89017589. Do not install orange P/N 17113557. Inspect the intake-to-head deck for warpage. The retrieved text does not give a measurement limit.

Later
Lean codes are a different claim

Both banks lean can be one shared air leak, and that is worth proving. It is not what this bulletin titles. Do not add a coolant-loss finding from this row.

What this is not The Jeep’s MultiAir oil-starvation story does not apply. Chronic oil use can still be recognized on this truck as a trend, but the high-band cascade from oil loss into a MultiAir actuator is gated to the Tigershark family and will not fire here.

PART 05

What the software can honestly name

The running app only proves classes in the generic view. That view is SAE-portable. GM depth, today, is a higher-priority framing of knock-sensor and lean-fuel classes — the check order in Part 03 — not a separate ontology.

Air

Intake, EVAP, catalyst, oxygen. Prove the gas path with trims and a leak check before condemning electronics.

Electricity

Coils, injectors, heaters, sensor circuits. A circuit code names a path, not yet a dead part.

Mechanical

Misfire and cam/crank correlation. Isolate the cylinder before replacing the sensor that reported it.

Fluid

Oil and coolant. Level, quality, and temperature come before blaming an actuator. The intake-gasket bulletin does not add a coolant-seal failure.

Variable

One-bank misfire, outside the ontology file

Corroborated shop prior, not a fetched bulletin A GM Preliminary Information numbered PIP3056 (dated 2004 in reposts) is widely quoted for 1997–2005 Gen III V8s: a P0300 from two to four cylinders on the same bank, sometimes with a fuel-trim code on that bank. The quoted checks are an injector balance test (one bad injector can misfuel a whole bank), inspection of that bank’s upstream oxygen-sensor connector for water — passenger-side harnesses can get dripped on by A/C evaporator condensate — an exhaust-backpressure check, and swapping the upstream oxygen sensors side to side to see if the misfire moves. The original PI was not fetched. Use it as a ranked guess, behind the coil and injector circuit codes if those are already set.

A scan tool does not see these. They are here so a noise or a pedal change has an entity to attach to. Where the VIN is silent, the row says so.

Brakes

Hydro-boost is the HD design, not a VIN-list fact Trucks in this GVWR class assist the brake pedal with a hydraulic booster fed by the power-steering pump, not a vacuum can. NHTSA campaign 04V045000 describes an out-of-spec relief-valve bore on some 2003 Silverados: the O-ring can fracture and pedal or steering effort rises slightly while braking. The campaign matches this make, model, and year. It does not by itself prove this VIN is one of the roughly 68,875 units. A harder pedal still points first at the belt, fluid, and pump that feed the booster, and then at whether the recall repair was done.

Body

Tailgate cables — campaign match, not a VIN-list hit NHTSA 04V129000 names the galvanized cables that hold the tailgate open on certain 2003 Silverados. They corrode, weaken, and can fracture. If both fail, the tailgate drops onto the bumper. Inspect both cables. Whether this VIN was in the population, or already repaired, is a dealer question.

Ladder frame, cab, and bed are otherwise undescribed for this VIN. Nothing else about the body is documented here.

Quick-trace

Complaint, then the first entity to suspect, then why. Open the part when you need the full ranking.

Part 03 · Chain B

Only P0171, or only P0174
Part 04 · Part 05
That bank. Driver’s side is bank 1. Do not promote the shared gasket to first place until the other bank is lean too.

PART 11

Glossary

DTC
Diagnostic trouble code. A standardized identifier, such as P0332, stored by the PCM.
PID
Parameter ID. A live value a scan tool can request, such as coolant temperature or long-term fuel trim.
LTFT
Long-term fuel trim. The PCM’s learned fuel correction per bank. Positive means it is adding fuel (a lean condition). Negative means it is removing fuel (a rich condition).
Bank 1
Driver’s side of this engine. Cylinders 1, 3, 5, 7. P0171. Not the front knock sensor.
Bank 2
Passenger side. Cylinders 2, 4, 6, 8. P0174. Not the rear knock sensor.
RPO
Regular Production Option. The three-character build codes on the glovebox label. They name the transmission, axle, and options this VIN left with.
Aspect
Air, electricity, mechanical, or fluid. It chooses the first kind of check, not the verdict.
Cascade edge
A curated “if A is confirmed, watch for B.” Never a certainty, and never proof that B has already happened.
Primary
Read from the NHTSA record or the OEM document.
Corroborated
The original document was not reached. Independent secondary sources agree on the number, the codes, and the repair order.
